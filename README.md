# 智能障礙事件樹

智能障礙的數位策展網站：重大事件時間軸、738 篇剪報、426 篇研究與學生人數，並設有照片與訪談展區。

整個網站是一個檔案（`index.html`），不需要資料庫或伺服器程式，放到 GitHub Pages 或任何網頁空間就能用。

## 資料夾裡有什麼

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站本身。資料、版面與程式都在這一個檔案裡 |
| `cover.png` | 分享到社群或通訊軟體時顯示的預覽圖（1200×630） |
| `icon.png` | 瀏覽器分頁與手機主畫面上的圖示 |
| `.nojekyll` | 告訴 GitHub Pages 直接把檔案原樣送出。沒有傳到也可以正常運作 |
| `source/` | 原始碼與資料，之後要修改時用（見下方「之後要改內容」） |

網站只需要前三個檔案。`source/` 不放上去也可以，放上去的話任何人都能看到。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的 repository。免費帳號要設成公開（Public）才能用 GitHub Pages。
2. 進到 repository，按 **Add file → Upload files**，把這個資料夾裡的檔案和 `source` 資料夾拖進去，再按 **Commit changes**。`index.html` 要在最外層，不要包在另一個資料夾裡。
3. 按 **Settings**，左邊選 **Pages**。在「Build and deployment」的「Source」選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等一兩分鐘再重新整理 Pages 這一頁，上方會出現網址，樣子是 `https://你的帳號.github.io/repository名稱/`。

之後要更新，把新的 `index.html` 再上傳一次蓋過去就可以，網址不變。

### 分享預覽圖的網址

有些社群與通訊軟體只認完整的網址。拿到網站的網址之後，做其中一件事：

- 會用 Python：執行 `python3 source/build.py --site https://你的帳號.github.io/repository名稱/`，再把新的 `index.html` 上傳。
- 不用 Python：用文字編輯器打開 `index.html`，找到 `<meta property="og:image" content="cover.png">` 這一行，把 `cover.png` 改成 `https://你的帳號.github.io/repository名稱/cover.png`。

預覽圖上寫著事件、剪報與研究的數量。資料的數量改變時，預覽圖需要重畫。

## 年表展區

網站的第二個展區（`#chron`）：橫向捲動的大事年表，1962 到 2024 年。上方是照年份比例畫的時間尺。怎麼分道有五個版本可以切換比較（`75-chron.js` 的 `CR_VERS`）：A 政府／民間、B 三個主題、C 大事／資料、D 不分道、E 誰的聲音。臺灣的 26 件大事畫成實心圓形；由剪報、研究、學生人數算出的 26 個轉折點畫成空心的方形、三角形、六角形。

- 大事裡有 12 件直接取自事件樹的「智能障礙重大事件表」（程式裡寫 `tree:'q1'` 這樣的代號），名稱與說明會跟著 `00-data.js` 一起更新；其餘 14 件取自法規資料庫與相關團體的沿革，來源寫在每件事的說明裡。
- 每件事放在哪一道，由各版本的 `of(e)` 決定；用到的名單是 `CR_GROUPS`（家長與團體）、`CR_TOOLS`（學者編的評量工具）、`CR_T_NAME`、`CR_T_EDU`（B 版的主題）。決定採用哪一版之後，可以把其他版本刪掉，或把預設改成那一版。
- 國際的 24 件大事還留在 `CR_RAW` 裡（`lane:"intl"`），目前不顯示；要放回來時改 `CR` 的篩選即可。
- 26 個轉折點的數字由 `source/data.json` 算出，寫在 `75-chron.js` 裡；資料更新時要重算。
- 公開前請再確認兩件事的出處：1970 年《特殊教育推行辦法》、1976 年第一次特殊兒童普查。
- **照片、剪報、訪談**：寫在 `source/src/60-media.js` 的 `PHOTOS`、`CLIPS`、`INTERVIEWS` 清單，加上 `ev:'年表事件的 id'`（訪談可用 `evSegs` 指定第幾段），就會出現在年表那件事的說明裡，名稱後面也會出現小圖示。檔案放在 `photos/`、`clips/`、`audio/`。照片一定要寫 `alt`（畫面描述），剪報一定要寫 `text`（打好的內文），訪談一定要有逐字稿。清單裡只要有真實資料，示意素材就不會出現。
- **易讀版**：`75-chron.js` 的 `CR_EASY`，每件大事、剪報、研究、人數各一段。目前是草稿，審閱後把 `CR_EASY_DRAFT` 改成 `false`。
- **逐字稿**：可以用開源的語音辨識 Breeze-ASR-25（MediaTek，針對臺灣華語）在自己的電腦上產生帶時間的草稿，再人工校對。訪談有個人資料，不要上傳到雲端服務。
- 要另外產生「只有年表」的單頁（沒有其他展區與連結）：`python3 source/build.py --chron 年表.html`。產生的檔案沒有 `<html><head><body>` 外殼，是給 claude.ai Artifact 用的。

## 之後要改內容

原始碼在 `source/src/`，改完之後執行：

```
python3 source/build.py
```

會重新產生最外層的 `index.html`。只用到 Python 內建的功能，不需要安裝其他東西。

| 要改什麼 | 改哪個檔案 |
| --- | --- |
| 「關於」頁的文字，包括還沒填的計畫名稱、執行單位、引用與授權 | `source/src/body.html`（搜尋「待填」） |
| 放入照片與訪談 | `source/src/60-media.js` 最上面的兩個清單，檔案開頭有範例 |
| 重大事件的名稱、日期、說明 | `source/src/00-data.js` |
| 年表的事件與轉折點 | `source/src/75-chron.js`（檔案開頭有格式說明） |
| 顏色、字級、間距 | `source/src/style.css` |

不想執行程式的話，也可以直接用文字編輯器改 `index.html` 裡相同的段落（例如搜尋 `const PHOTOS`）。這樣改的內容不會回到 `source/`，下次執行 `build.py` 會被蓋掉，所以兩種方式請擇一。

### 放入照片與訪談

1. 在 `index.html` 旁邊建立 `photos` 與 `audio` 兩個資料夾，把檔案放進去。
2. 在 `source/src/60-media.js` 最上面的 `PHOTOS` 與 `INTERVIEWS` 清單裡，照著範例各加一筆。
3. 清單裡只要有一筆真實資料，版面示意就不再顯示。

每張照片要寫 `alt`（給看不到圖片的讀者的畫面描述）。每段訪談要附逐字稿；`dur`（全長的秒數）沒有寫的話，網頁會自己從錄音檔讀。

檔案大小：GitHub 網頁上傳每個檔案上限 25 MiB，一次最多 100 個檔案；整個網站不能超過 1 GB。錄音檔比較大時，可以轉成單聲道、位元率較低的 mp3。

### 資料（Excel）有更新時

```
pip install openpyxl
python3 source/build_data.py 新聞編碼.xlsx 文獻.xlsx 學生人數.xlsx source/data.json
python3 source/build.py
```

`build_data.py` 的開頭寫了每個 Excel 需要哪些工作表。它會印出一份檢查報告，請對一下篇數與各種編碼的次數。

## 公開之前請確認

- **姓名**：剪報標題取自整理時的檔名，少數含有當事人的姓名。備註欄沒有放進網站。
- **原始檔**：Excel 與 Word 原始檔含有個人資料，這個資料夾裡沒有，也請不要放進公開的 repository。
- **照片與訪談**：目前是版面示意，不是真實資料。放入真實內容前，請確認授權與受訪者的同意範圍。
- **「關於」頁**：計畫名稱、執行單位、主持人與團隊、執行期間、經費來源、聯絡方式、引用與授權，目前都是「待填」。

## 資料整理備忘

這些是整理資料時遇到、需要知道的地方，網站的「關於」頁也有說明。

- 剪報 738 篇。721 篇的日期取自「0815合併原始檔」的日期欄，其餘 17 篇對不到，用檔名開頭的日期。
- 有 1 篇的年份欄是 1999，日期欄與檔名是 1990 年 3 月 23 日。網站依日期歸在 1990 年。
- 主題欄有 1 筆只有數字「25」，沒有對應的主題，已略過。
- 有 1 篇沒有編主題，1 篇沒有編用詞；主要觀點編為「無」或沒有填的共 181 篇，不畫在觀點的圓圈圖裡，另外寫出篇數。
- 原表有 18 篇標記為「有出現關鍵字但主體非智能障礙者」。這些仍計入統計，在剪報清單裡會標示。
- 較少見的 37 種用詞寫法（各出現 1 到 3 次，共 43 次）歸為「其他用詞」。
- 新聞資料到 2022 年。時間軸背景的用詞比例畫到 2022 年底，2023 年以後留白。
- 學生人數的腦性麻痺欄位，較早的年度填的是 0，圖上不畫。

## 無障礙

- 2026 年 10 月以 axe-core 4.14 檢查（規則範圍：WCAG 2.0、2.1、2.2 的 A 與 AA，以及 best-practice）。檢查了各展區的 24 種畫面狀態，電腦與手機版面、淺色與深色各一次，沒有違反項目。
- 圖表裡的文字另外以畫面像素計算對比，都達到 WCAG AA 的要求（一般文字 4.5:1，大字 3:1）。
- 自動檢測只涵蓋一部分準則。網站尚未以螢幕報讀軟體實機測試，也還沒有請身心障礙使用者試用。
- 版面只在 Chromium 模擬的電腦與手機尺寸測試過，尚未在實體 iPhone、Android 手機與 Safari、Firefox 上確認。

## 其他說明

- **字型**：網頁會向 Google Fonts 載入思源宋體、思源黑體與霞鶩文楷。載不到時改用裝置內建的字型，版面不受影響。
- **瀏覽紀錄**：是否看過導覽，記在瀏覽者自己的瀏覽器裡（localStorage），沒有傳到任何地方。網站沒有使用追蹤或統計工具。
- **網址**：每個展區有自己的網址（例如 `…/#news`），可以直接分享。瀏覽器的「返回」會回到上一個展區。
- **Google Apps Script**：要發布成 Apps Script 網頁應用程式時，執行 `python3 source/build.py --gas 資料夾名稱`，會產生 `Index.html` 與 `Code.gs`，部署步驟寫在 `Code.gs` 開頭。
